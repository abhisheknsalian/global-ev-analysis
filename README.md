## 🌍 Overview

This project explores global Electric Vehicle (EV) adoption trends using the **International Energy Agency (IEA) EV Data Explorer 2025** dataset.

The project combines exploratory data analysis with an interactive multi-page Streamlit dashboard to provide insights into EV sales, stock growth, regional adoption, and country-level market performance.

---

## ✨ Features

- 📊 Interactive Streamlit Dashboard
- 🌍 Global EV Sales & Stock Analysis
- 📈 Interactive Plotly Visualizations
- 🗺️ Country-wise EV Adoption Analysis
- 🌳 Regional Market Share Treemap
- 🔥 Market Growth Heatmap
- 📑 Exploratory Data Analysis (EDA)
- ⚡ Clean and Modular Project Structure

## 📂 Dataset

**Source:** International Energy Agency (IEA)

**Dataset:** EV Data Explorer 2025

The dataset includes:

- 🚗 EV Sales
- 🚙 EV Stock
- 🌎 Countries & Regions
- ⚡ Battery Electric Vehicles (BEV)
- 🔋 Plug-in Hybrid Electric Vehicles (PHEV)
- 📅 Historical Trends

## 📈 Key Insights

- 🚗 Global EV adoption has accelerated rapidly since 2020.
- ⚡ Battery Electric Vehicles (BEVs) dominate the global EV market.
- 🇨🇳 China is the world's leading EV market.
- 🇪🇺 Europe continues to be one of the fastest-growing EV regions.
- 🌍 EV adoption remains concentrated in a relatively small number of countries.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/abhisheknsalian/global-ev-analysis.git
```

Navigate to the project

```bash
cd global-ev-analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the dashboard

```bash
cd dashboard
streamlit run app.py
```
